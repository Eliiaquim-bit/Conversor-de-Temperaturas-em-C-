# Conversor-de-Temperaturas-em-C-
Programa em linguagem C para converter temperaturas
Crie um programa simples em C, para executar no OnlineGDB, que faça a conversão de temperaturas entre Celsius, Fahrenheit e Kelvin.

O programa deve ter um menu interativo, permitir que o usuário escolha a conversão, informe a temperatura e mostrar o resultado. Inclua uma opção para sair.

Use apenas conceitos básicos de C, como printf, scanf, variáveis, operações matemáticas e if/else ou switch. O código deve estar pronto para copiar, colar e executar no OnlineGDB.
